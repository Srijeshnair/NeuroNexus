 📝 Google Form Style Registration Form

A simple and responsive **HTML & CSS registration form** inspired by the clean design of Google Forms. This form includes various input types like text fields, dropdowns, radio buttons, and a textarea, making it suitable for a variety of use cases like event registration, feedback collection, and user onboarding.

 🚀 Features

- Fully responsive layout
- Clean and modern design
- Form fields include:
  - Full Name
  - Contact Number
  - Address
  - Company Name
  - Email Address
  - Department (Dropdown)
  - Gender (Radio buttons)
- Built using pure HTML & CSS (no frameworks)
